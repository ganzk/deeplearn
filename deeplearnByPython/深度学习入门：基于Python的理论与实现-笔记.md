import numpy as np

# 3层神经网络实现
# 第一层

print(A1)

B2 = np.array([0.1, 0.2])
A2 = np.dot(Z1, W2) + B2
Z2 = af.sigmoid(A2) # 激活函数
print(A2)
print(Z2)

# 输出层
W3 = np.array([[0.1, 0.3], [0.2, 0.4]])
B3 = np.array([0.1, 0.2])
A3 = np.dot(Z2, W3) + B3
Z3 = af.identity_function(A3) # 输出函数
print(A3)
print(Z3)

#### softmax函数
预测一个样本属于N个互斥类别中每一个的概率。所有输出概率之和应为1
Softmax 不仅将每个输出值转换为概率，还**放大了最大值的比重**，使得概率分布更加明显。
Softmax函数可以将上一层的原始数据进行归一化，转化为一个之间的数值，这些数值可以被当做概率分布，用来作为多分类的目标预测值。Softmax函数一般作为神经网络的最后一层，接受来自上一层网络的输入值，然后将其转化为概率。

```python
# softmax函数   输出总和为1是softmax函数的一个重要性质
# 因为和为1 每个输出值代表该神经元对应类别的概率。
# 单调递增函数
# 所以 索引 x 的大小影响这y大小,如果只是输出一个最大概率，其实只看x里面最大的数值就行，这种情况输出层这个函数可以省略
def softmax(x):
    # 防止数值过大
    c = np.max(x)
    exp_x = np.exp(x-c)
    sum_exp_a = np.sum(exp_x)
    y = exp_x / sum_exp_a
    return y
```

## 神经网络学习

“学习”是指从训练数据中自动获取最优权重参数的过程。

> [!NOTE] 学习步骤
> 为了更好的理解如何进行的学习，我们先了解学习步骤，方便接下来的理解
> ### 核心比喻：蒙眼调酒师
> 想象一下，你的目标是训练一位**蒙着眼睛的调酒师**调出一杯“完美”的莫吉托鸡尾酒。
>1. **输入**：你给他各种原料——朗姆酒、苏打水、薄荷叶、糖、青柠。（这相当于神经网络的**输入数据**）。
 >   
>2. **初始状态**：由于他蒙着眼，他一开始完全不知道配方，只能**随机地**混合各种原料的比例。（这相当于神经网络拥有**随机的初始权重**）。
  >  
>3. **输出与反馈**：他调好一杯递给你。你尝了一口，然后根据你的经验（比如太苦了、不够甜），给出一个评价：“这杯离完美的莫吉托还差得远，我给它的‘难喝程度’打 8 分（满分 10 分难喝）。”（你的评价就是**损失函数**计算出的**损失值**）。
  >  
>4. **关键的学习步骤**：现在，调酒师需要根据你的反馈来改进。他会问你：“是哪方面出了问题？” 你回答：“主要是**太苦了**，可能糖放少了，也可能青柠放多了。”
 >   
>    - 他听到“太苦了”，就知道最终效果需要**更甜**。
>        
>    - 他根据自己模糊的记忆，推测：“**加糖**应该能让酒变甜，**少放青柠**也能减少酸苦味。”
 >       
 >   - 于是，他决定下一次**稍微增加糖的比例**，并**稍微减少青柠的比例**。
>        
>    - （这个“推测哪个原料负责哪个味道，并决定如何调整”的过程，就是**反向传播**和**梯度下降**）。
>        
>5. **迭代**：调酒师根据你的反馈，调整了配方，又调出了第二杯。你再品尝，再给出反馈（比如，“难喝程度”降到了 5 分）。如此循环往复几百次、几千次……
 >   
>
>最终，经过无数次的尝试和调整，这位蒙眼调酒师终于能稳定地调出一杯非常好喝的莫吉托。他**自己学会了一套完美的原料配比**，尽管他从未亲眼见过配方。
>### 二、技术层面的详细拆解
>
现在，我们把比喻对应到神经网络的技术术语上。
>
**一个神经网络主要由以下部分组成：**
>
>- **神经元**：接收输入、进行简单计算并产生输出的基本单元。
   > 
>- **连接权重**：每个神经元连接上都有一个**权重**，它代表了该连接的重要性。**学习本质上就是学习这些权重的最佳值。**（对应调酒师手中的原料配比）。
 >   
>- **偏置**：另一个可学习的参数，可以增加模型的灵活性。
  >  
>- **激活函数**：为网络引入非线性，让网络可以学习复杂的模式。
   > 
>
>#### 学习过程的四个核心步骤：
>
假设我们要训练一个识别猫图片的网络。
>
**步骤 1：前向传播 —— “猜一猜”**
>
>- 将一张猫的图片（像素数据）输入网络。
   > 
>- 数据从输入层开始，经过层层加权求和与激活函数的计算，最终在输出层产生一个结果。比如，输出可能是 `[0.7, 0.3]`，表示网络“认为”这张图有 70% 的概率是猫，30% 的概率是狗。
  >  
>- （这相当于调酒师调出了第一杯酒。）
  >  
>
**步骤 2：计算损失 —— “算算差多远”**
>
>- 我们将网络的预测结果 `[0.7, 0.3]` 与真实标签 `[1, 0]`（代表它是猫）进行比较。
   > 
>- **损失函数** 会计算出两者之间的差距（即“损失值”）。一个常见的损失函数是均方误差：`Loss = (1 - 0.7)² + (0 - 0.3)² = 0.09 + 0.09 = 0.18`。
  >  
>- （这相当于你品尝后给出的“难喝程度 8 分”。）
  >  
>
**步骤 3：反向传播 —— “找出谁的责任”**
>
>- 这是最关键的一步。目标是回答：“**损失函数计算出的这个误差，应该如何归因于网络中的每一个权重？**”
  >  
>- 通过微积分中的**链式法则**，从输出层开始，**反向**逐层计算每个权重对于最终损失的**贡献度**（即**梯度**）。
  >  
>- （这相当于你告诉调酒师“太苦了”，而他内部推测出“是糖和青柠的比例出了问题”。）
   > 
>
**步骤 4：梯度下降 —— “动手调整”**
>
>- 现在我们知道了每个权重的“责任”有多大（梯度），接下来就可以进行调整了。
   > 
>- **学习率** 是一个超参数，它决定了每次调整的**步长**。调整的规则非常简单：  
 >   `新权重 = 旧权重 - 学习率 × 该权重的梯度`
  >  
>- **梯度** 指明了**方向**（为了让损失下降，权重应该增加还是减少）。
   > 
>- **学习率** 控制了**步幅**（每次改变多少）。
   > 
>- （这相当于调酒师决定“下次多加点糖，少加点青柠”。）
   > 
>
>#### 循环迭代
>
>一次“前向传播 -> 计算损失 -> 反向传播 -> 梯度下降”的过程，称为一个 **“训练迭代”**。
>
我们将整个训练集（成千上万张带标签的图片）分成多个小批次，一遍又一遍地喂给网络。每一个批次都会让网络的所有权重进行一次微调，使得网络的预测结果越来越接近真实答案。
>
最终，经过成千上万次迭代后，网络的权重不再随机，而是被调整到了一组能够出色完成特定任务（如识别猫）的**最优值**。这时，我们就说这个神经网络已经“学会”了。
>
>### 总结
>
神经网络的学习，就是一个通过**大量数据**驱动，利用**梯度下降**算法，在**反向传播**的指引下，**持续地、微调**其内部数百万甚至数十亿个**连接权重**，以**最小化预测错误（损失）** 的自动化过程。它不是在“记忆”，而是在寻找数据中深层次的、统计上的**规律和模式**。

**训练数据和测试数据**
机器学习中，一般将数据分为训练数据和测试数据两部分来进行学习和实验等。首先，使用训练数据进行学习，寻找最优的参数；然后，使用测试数据评价训练得到的模型的实际能力。
为什么需要将数据分为训练数据和测 试数据呢？因为我们追求的是模型的泛化能力。为了正确评价模型的**泛化能力**，就必须划分训练数据和测试数据。另外，训练数据也可以称为**监督数据**。

> [!NOTE] 泛化能力
> 泛化能力是指处理未被观察过的数据（不包含在训练数据中的数据）的 能力。获得泛化能力是机器学习的最终目标。个模型的最终目标不是为了完美复述训练数据，而是要解决现实世界中的新问题。
> 模型在**训练数据**上表现极好，但在**新数据**上表现很差这种叫做**过拟合**,
> **原因**：模型过于复杂，它不仅仅学习了数据中普遍的、底层的规律，还**“记忆”了训练数据中的噪声和随机波动**。
> 模型在**训练数据**和**新数据**上都表现得很差这种叫做**欠拟合**。
> **原因**：模型过于简单，甚至无法捕捉训练数据中蕴含的**基本规律**。
> 解决方案：
> 1.**正则化**：一种通过**在损失函数中增加惩罚项**来故意限制模型复杂度的技术。它强迫模型保持“简洁”，优先学习那些最重要的特征，避免去记忆噪声。
> 2.**验证集**：从训练数据中分出一部分**不参与训练**，专门用来在训练过程中模拟“新数据”，以评估模型的泛化能力。我们会根据模型在验证集上的表现来调整参数和选择最佳模型。相当于模拟考
> 3.**更多的优质数据**：数据量越大、质量越高、覆盖的场景越全面，模型就越容易学到普适的规律，而不是拘泥于少数样本的特例。

### 损失函数

**损失函数（Loss Function）** 是机器学习和深度学习中的核心组件，用于**量化模型预测结果与真实值之间的差距**。它如同一个“误差计分器”，指导模型通过优化算法（如梯度下降）调整参数，逐步减少预测错误。
输入是模型的预测值和真实值，输出就是是一个非负数值，这个值被称之为**损失**或者**误差**，**预测得越准确，损失值就越低；预测得越离谱，损失值就越高。**

#### 均方误差
$$
E = \frac{1}{n}\sum_{i=1}^{n}{(y_i - \hat{y_i})^2}
$$
其中：
- n：样本的总数量。
- ∑：求和符号，表示把后面所有的值加起来。
- i：第 `i` 个样本。
- $y_i$：第 `i` 个样本的**真实值**。
- $\hat{y_i}$：第 `i` 个样本的**预测值**。
- $(y_i−\hat{y_i})$：这就是第 `i` 个样本的**误差**。

**计算步骤：**
1. **计算每个样本的误差**：`真实值 - 预测值`
2. **对每个误差进行平方**：`(误差)²`（这确保了所有值都为非负数，并且放大了大误差）
3. **将所有平方误差求和**：`Σ(平方误差)`
4. **求平均值**：将总和除以样本数量 `n`。.
**均方根误差**：就是将得到的值开根号

**代码实现**
```python
# 均方误差函数  
def mean_squared_error(y, t):  
    return 0.5 * np.sum((y-t)**2)
```

**用途**
均方误差通常用于**回归问题**，比如预测房价、气温、销量等，对**异常值（ outliers）** 非常敏感。因为误差被平方了，一个巨大的误差会被放大得非常多，这会强烈地影响模型

**总结**
- **是什么**：均方误差是回归任务中最常用的损失函数之一，计算的是预测值与真实值之差的平方的平均值。
- **核心特点**：通过**平方**操作，**严厉惩罚较大的误差**。
- **主要用途**：指导回归模型（如线性回归、神经网络回归）的训练，通过最小化MSE来找到最优的模型参数。
- **优点**：数学性质好，便于优化。
- **缺点**：对**异常值**非常敏感。

> [!NOTE] 为什么是平方
> 1.**放大较大误差**
> 2.**数学性质优良**：平方函数是一个**光滑的、可导的凸函数**。这个性质对于使用**梯度下降**等优化算法至关重要，因为它能让我们轻松地计算出损失函数下降最快的方向。
> 3.**方便计算**


#### 交叉熵误差

$$
H(P,Q) = -\sum_i{P(i)\log{Q(i)}}
$$
其中：
- `i` 遍历所有的类别（如A, B, C, D选项）。
- `P(i)` 是真实分布中类别 `i` 的概率。
- `Q(i)` 是模型预测的分布中类别 `i` 的概率。
由于 `P(i)` 只有在真实类别 `c` 上为1，其他都为0，所以这个求和公式可以**极大地简化**为：
$$CrossEntropyLoss = -\log{Q(c)}$$
其中`c`就是**就是真实的那个类别标签。** 
比如**真实分布 P**: `[1, 0, 0]`，Q为`[0.9, 0.1, 0.0]`那么`Loss = -log(0.9) ≈ 0.105`

> [!NOTE] 为什么P中有一个是1其他为0
> 这是`one-hot`,因为分类问题里面只有类别，所以用不同位置的1表示不同的类别；
> 比如`[1, 0, 0]`代表猫，`[0, 1, 0]`代表狗，`[0, 0, 1]`代表鸟，1代表真实类别
> 所以` P(i) 只有在真实类别 c 上为1`这句话可以更好地理解
> 当然`one-hot`也有缺点，缺点就是

def cross_entropy_error(y, t):  
    delta = 1e-7 # 为了确保不生成log0,导致无穷大产生报错  
    return -np.sum(t * np.log(y + delta))

t = [1, 0, 0]  
y = [0.9, 0.1, 0.0]  
h = cross_entropy_error(np.array(y), np.array(t))

**特性**
1. **对错误“零容忍”**：  
    当模型给正确类别分配的概率为 **0** 时，损失会变为无穷大 `(-log(0) = ∞)`。这强烈地惩罚了完全错误的预测，迫使模型在训练过程中必须给正确的类别分配一定的概率。
2. **与Softmax激活函数的完美配合**：  
    在神经网络的分类任务中，通常最后一层会使用 **Softmax 函数**，它将网络的原始输出（ logits ）转换为一个概率分布（所有值在0到1之间，且和为1）。**交叉熵误差与Softmax结合时，在反向传播中会产生一个非常干净、优雅且高效的梯度**。这个梯度简单到就是 `(预测概率 - 真实概率)`，这使得模型更新非常直接和快速。
3. **梯度信号清晰有力**：  
    当模型预测很糟糕时（比如正确类别的概率很低），梯度会很大，意味着模型参数会进行大幅更新以快速纠正错误。当模型预测很准确时，梯度会很小，参数只需微调。这种“自适应的”梯度特性使得模型学习效率非常高。
4. **与极大似然估计的等价性**：  
    最小化交叉熵误差在数学上完全等价于执行**极大似然估计**。也就是说，通过最小化交叉熵，我们实际上是在寻找一组模型参数，使得观察到当前这批真实数据的“可能性”是最大的。这从统计学的角度为交叉熵提供了坚实的理论依据。

**为什么分类问题不用均方差**
回顾一下，均方误差会直接计算概率值的平方差：
- 不如预测值为`[0.1, 0.8, 0.1]`，它得MSE为 `(1-0.1)² + (0-0.8)² + (0-0.1)² = 0.81 + 0.64 + 0.01 = 1.46`。
虽然MSE也很大，但相比交叉熵的$-\log{0.1} = 2.3$，它的“惩罚感”不那么强烈和直接。更重要的是，MSE在训练后期（当预测接近正确时）会导致梯度变得非常小，学习速度变慢，而交叉熵则能提供持续强劲的梯度信号。

**交叉熵误差是分类任务，特别是多分类任务的“黄金标准”损失函数。**
- **它是什么**：一个衡量**预测概率分布**与**真实概率分布**之间差异的指标。
- **它做什么**：它**严厉惩罚**“模型对正确类别缺乏信心”和“做出完全错误预测”的行为。
- **为何有效**：它与Softmax配合能产生**高效、清晰的梯度**，极大地加速和稳定了模型的训练过程，其背后有坚实的**信息论**和**统计学**理论基础。

#### 为什么要引入损失函数

设定损失函数主要有以下几个根本原因：
1.**提供量化的反馈信号**
模型由数百万甚至数十亿个参数组成，它自己不知道“对”与“错”。损失函数将“错误”这个概念**量化**。模型预测得越离谱，损失值就越高。这个数字为模型提供了清晰、无歧义的反馈：“你这次做得有多糟。”
> **好比**：教练不能只对运动员说“你跑得不好”，而必须说“你百米跑了13秒，你的目标是11秒”。13秒这个量化的数字，才是运动员改进的依据。

2.**定义优化的明确目标**
机器学习的整个过程可以被归结为一句话：**最小化损失函数**。  
这个目标极其明确，且可执行。所有的努力都指向同一个方向——让这个数字变小。
> **好比**：公司的目标是“利润最大化”。利润就是一个清晰、可量化的目标，所有部门都围绕它开展工作。

3 **指引学习的方向（梯度）**
这是最关键的一点。仅仅知道“现在有多糟”是不够的，还需要知道“该如何改进”。  
损失函数的数学特性（通常是可微的）允许我们计算**梯度**。梯度告诉模型，每一个参数应该**向哪个方向**（增加还是减少）以及**调整多少**，才能最有效地降低损失。
> **好比**：你的高度计不仅能显示海拔，还能告诉你哪个方向是下坡路。你沿着最陡的下坡路走，就能最快地到达谷底。这个“下坡方向”就是梯度。

4 **作为模型选择和评估的客观标准**
当你有多个不同的模型（比如一个神经网络和一个决策树）时，你如何客观地判断哪个更好？你不能凭感觉，而需要在同一个**验证集**上计算它们的损失函数值。损失值更低的那一个，就是性能更好的模型。


**线性回归的例子**
假设我们用 `y = w*x + b` 这个模型来预测房价。
- **目标**：找到最佳的 `w`（权重）和 `b`（偏置）。
- **没有损失函数**：我们只能随机猜测 `w` 和 `b`，然后“感觉”一下预测得准不准。这是完全不可行的。
- **设定损失函数（如均方误差MSE）**：
    - 现在，对于任何一组 `(w, b)`，我们都可以计算出一个具体的 `MSE` 值。
    - 我们的目标变成了：找到使 `MSE` 最小的那组 `(w, b)`。
    - 通过计算 `MSE` 对 `w` 和 `b` 的梯度，我们可以知道：
        - 是该增加 `w` 还是减少 `w`？
        - 是该增加 `b` 还是减少 `b`？
    - 然后我们按照梯度指示的方向，一点点调整 `w` 和 `b`，`MSE` 就会逐渐下降，模型预测也就越来越准。

**总结**
假设有一个神经网络，现在我们来关注这个神经网络中的某一个权重参 数。此时，对该权重参数的损失函数求导，表示的是“如果稍微改变这个权 重参数的值，损失函数的值会如何变化”。如果导数的值为负，通过使该权 重参数向正方向改变，可以减小损失函数的值；反过来，如果导数的值为正， 则通过使该权重参数向负方向改变，可以减小损失函数的值。不过，当导数 的值为0时，无论权重参数向哪个方向变化，损失函数的值都不会改变，此 时该权重参数的更新会停在此处
在进行神经网络的学习时，不能将识别精度作为指标。因为如果以 识别精度为指标，则参数的导数在绝大多数地方都会变为0。

> [!NOTE] 为什么不能用识别精度作为指标
> 假设某个神经网络正 确识别出了100笔训练数据中的32笔，此时识别精度为32%。如果以识别精 度为指标，即使稍微改变权重参数的值，识别精度也仍将保持在32%，不会出现变化。也就是说，仅仅微调参数，是无法改善识别精度的。即便识别精 度有所改善，它的值也不会像32.0123...%这样连续变化，而是变为33%、 34 %这样的不连续的、离散的值。而如果把损失函数作为指标，则当前损 失函数的值可以表示为0.92543...这样的值。并且，如果稍微改变一下参数 的值，对应的损失函数也会像0.93432...这样发生连续性的变化。
> 
> 作为激活函数的阶跃函数也有同样的情况。出 于相同的原因，如果使用阶跃函数作为激活函数，神经网络的学习将无法进行。阶跃函数的导数在绝大多数地方（除了0以外的地方）均为0。 也就是说，如果使用了阶跃函数，那么即便将损失函数作为指标，参数的微 小变化也会被阶跃函数抹杀，导致损失函数的值不会产生任何变化。
> 
> 而sigmoid函数，不仅函数的输出（竖轴的值）是连续变化的，曲线的斜率（导数） 也是连续变化的。也就是说，sigmoid函数的导数在任何地方都不为0（但是在两端饱和区域梯度（导数）非常小，容易导致“梯度消失”问题）。这对神经网络的学习非常重要。

#### 什么是梯度

梯度是一个数学工具，它告诉你：
1. 在当前位置，哪个方向能让函数值上升得最快？
2. 在这个最快的方向上，函数值上升的“陡峭程度”是多少？

简单来说，**梯度就是“指向最陡峭上升方向的指南针”**。梯度指示的方向是各点处的函数值减小最多的方向

**数学定义**
在数学中，梯度是一个**向量**（一个有方向和大小的量），通常用符号 **∇**（读作“Nabla”）或 **grad** 表示。
对于一个多元函数（比如 `f(x, y)`），它的梯度包含了这个函数对所有自变量的**偏导数**。

> [!NOTE] 如何理解这个向量
> **向量的分量 (∂f/∂x, ∂f/∂y)**：分别代表了函数在 x 轴方向和 y 轴方向上的变化率（即斜率）。
> **向量的方向**：当把这些方向上的变化率组合成一个向量时，它的方向就神奇地指向了函数值增长最快的方向。
> 例子：
> 假设我们有一个描述地形的函数：$f(x,y) = x^2 + x^3$ 
> 
> 1.**计算偏导数**
> $∂f/∂x = 2x$
> $∂f/∂y = 3x$
> 
> 2.**得到梯度**
> $∇f = (2x, 3y)$
> 
> 3.**在特定点分析梯度**
> 在点 **(1, 1)**，梯度是 **∇f = (2, 3)**。
> 
> **(2,3)是一个向量，意思是**
> 当我们在点 `(1, 1)` 计算出梯度是 `(2, 3)` 时，我们的意思不是说梯度在 `(2, 3)` 这个位置。我们的意思是：
**“在你当前的位置 `(1, 1)`，函数增长最快的方向，是沿着向量 `(2, 3)` 所指的方向。”**
我们在点 `(1, 1)` 处，画上一个**从 `(1, 1)` 出发，指向 `(1+2, 1+3) = (3, 4)` 的箭头**。这个箭头就代表了梯度向量。
> 

**代码**
```python

# 多元函数  
def function_2(x):  
    return x[0] ** 2 + x[1] ** 3

# 梯度  就是计算所有变量的偏导数
def numerical_gradient(f, x):  
    h = 1e-4 # 0.0001  
    grad = np.zeros_like(x) # 生成和x形状相同的数组，现在里面全是0，用来返回数据 
    for idx in range(x.size):  
        tmp_val = x[idx]  
        # f(x+h) 的计算  
        x[idx] = tmp_val + h  
        fxh1 = f(x)  
        # f(x-h) 的计算  
        x[idx] = tmp_val - h  
        fxh2 = f(x)  
        # 对idx当前变量通过数值微分的方式求导
        grad[idx] = (fxh1 - fxh2) / (2*h)  
        x[idx] = tmp_val # 还原值  
    return grad

# 求 f = x1**2 + x2**3 在（1,1）的梯度  
s = numerical_gradient(function_2, np.array([1.0, 1.0]))  
print(s)

-------------------------------------------------
[2.         3.00000001]

```



**负梯度**

负梯度就是梯度的反方向。
- **梯度 (2, 3)**：你的身体感觉告诉你，**朝东偏北56度**方向爬，是上山最快、最陡的路。
    
- **负梯度 (-2, -3)**：你直接转身180度，**朝西偏南56度**方向走，是下山最快、最陡的路。

**数学上的表示**
如果梯度 **∇f = (2, 3)**，那么：  
**负梯度 = -∇f = (-2, -3)**

- **方向**：从原来的东偏北56度，变成了西偏南56度。
    
- **大小**：和原梯度一样陡峭，只是方向完全相反。

#### 梯度法

机器学习的主要任务是在学习时寻找最优参数。同样地，神经网络也必须在学习时找到最优参数（权重和偏置）。这里所说的最优参数是指损失函数取最小值时的参数。一般而言，损失函数很复杂，参数空间庞大，我们不知道它在何处能取得最小值。而通过巧妙地使用梯度来寻找函数最小值（或者尽可能小的值）的方法就是梯度法。

在梯度法中，函数的取值从当前位置沿着梯度方向前进一定距离，然后在新的地方重新求梯度，再沿着新梯度方向前进， 如此反复，不断地沿梯度方向前进。通过不断地沿梯度方向前进，逐渐减小函数值的过程就是梯度法（gradient method）

**梯度法是一种通过“沿着最陡峭的下坡路走”来寻找函数最小值（或最大值）的数学方法。**


公式就是`新参数 = 旧参数 - 学习率 × 梯度`，
- `旧参数`就是当前位置
- `学习率 x 梯度`就是行进的步长
- `-`就是负梯度，朝减少的方向行进
$$
\begin{aligned} 
x_0 = x_0-η\frac{∂f}{∂x} \\
x_1 = x_1-η\frac{∂f}{∂x}
\end{aligned} 
$$
**表示朝向减少最多的方向前进**

η表示学习率，学习率决定在一次学习中，应该学习多少，以及在多大程度上更新参数。学习率需要事先确定为某个值，比如0.01或0.001。一般而言，这个值过大或过小，都无法抵达一个“好的位置”。在神经网络的学习中，一般会一边改变学习率的值，一边确认学习是否正确进行了。
- 如果学习率**太小**，下山速度会很慢，需要很多步才能收敛，训练时间很
	
-  如果学习率**太大**，一步迈得太远，可能会“跨过”最低点，甚至导致损失函数不降反升，无法收敛。

> [!NOTE] 超参数
> 像学习率这样的参数称为超参数。这是一种和神经网络的参数（权重和偏置）性质不同的参数。相对于神经网络的权重参数是通过训练数据和学习算法自动获得的，学习率这样的超参数则是人工设定的。


**代码**
```python
# 梯度下降 lr是学习率 step_num是重复次数 
# 可以用来找函数的极小值
def gradient_descent(f, init_x, lr=0.01, step_num=100):  
    x = init_x  
    for i in range(step_num):  
	    # 计算梯度
        grad = numerical_gradient(f, x)  
        x -= lr * grad  
    return

# 求 f = x1**2 + x2**3 极小值  
a = gradient_descent(function_2, np.array([-3.0, 4.0]), lr=0.1, step_num=100)  
print(a)

----------------------------------------------------------
[-3.22067705e-01 -4.90892359e+20]

```

可以看到上面的生成的值非常小，非常接近(0,0)，实际上，真的最小值就是(0，0)，所以说通过梯度法我们基本得到了正确结果。

#### 神经网络的梯度

神经网络的学习也要求梯度。这里所说的梯度是指损失函数关于权重参数的梯度。

神经网络的梯度就是损失函数 **L** 对所有参数 **W** 的**偏导数**构成的向量（或高维张量）。
**梯度 ∇L = \[ ∂L/∂w₁, ∂L/∂w₂, ..., ∂L/∂wₙ, ∂L/∂b₁, ∂L/∂b₂, ..., ∂L/∂bₘ ]**
$$
∇L = \begin{pmatrix} 
\frac{∂L}{∂w_{11}} & \frac{∂L}{∂w_{12}} & \cdots & \frac{∂L}{∂w_{1n}} \\
\frac{∂L}{∂w_{21}} & \frac{∂L}{∂w_{22}} & \cdots & \frac{∂L}{∂w_{2m}} 
\end{pmatrix}
$$

> [!why] why？为什么神经网络的梯度就是损失函数 L对所有W的偏导数构成的向量？损失函数中不涉及权重参数，为什么可以对权重进行偏导数?
> 因为**链式法则**，损失函数中的预测值就是权重参数W通过激活函数一步一步走到损失函数中的
> 
> 比如以最简单的线性回归为例，损失函数是均方误差（MSE）。假设模型为 y_pred = w\*x + b，损失函数 L = (y_true - y_pred)^2。  
>虽然损失函数直接看起来是y_pred的函数，而y_pred是w和b的函数，所以损失函数实际上是wb的复合函数。  
>因此，我们可以通过链式法则来求损失函数对w和b的偏导数。
>
>**损失函数确实不直接包含权重，但通过神经网络的前向计算过程，损失函数成为了权重的复合函数。链式法则让我们能够计算损失函数对任何权重的偏导数，无论这个权重在网络的哪个深处。**
>
>**当然这只是简单的模型，具体的操作是一层一层的从后往前计算，一直到第一层的输入，这就是反向传播**

### 反向传播

#### 反向传播理解

反向传播是神经网络用来​**​高效计算梯度​**​的算法。它的核心思想是：​**​利用链式法则，将损失函数的误差从输出层开始，反向传播到网络的每一层，从而计算出每个参数（权重和偏置）对总误差的贡献程度（也就是梯度）。​**

> [!NOTE] 链式法则
> 如果某个函数由复合函数表示，则该复合函数的导数可以用构成复合函数的各个函数的导数的乘积表示
> 
> 例：
> $z = (x + y)^2$， 它是由$z = t^2$ 和 (x+y) 组成
> 那么对x的导数是
> $$ \begin{aligned}
> \frac{δz}{δx} = \frac{δz}{δt}\frac{δt}{δx}
> \end{aligned}
> $$
> 
> 其中
> $$\begin{aligned}
> \frac{δz}{δx} = 2t \\
> \frac{δt}{δx} = 1
> \end{aligned}
> $$
> 
> 所以
> $$ \begin{aligned}
> \frac{δz}{δx} = \frac{δz}{δt}\frac{δt}{δx} = 2t \cdot 1 = 2(x+y)
> \end{aligned}
> $$


反向传播分为两个阶段
- **正向传播**：数据通过输入神经进入，每一层乘上权重加上偏置，通过激活函数得到输出，经过多层神经网络，最后通过输出什么输出值，这个值是预测值，然后通过损失函数计算与真实值的误差
- 反向传播：
	- 从输出层开始，首先计算输出层的输入值的梯度，输出层输入设置为w，输出层的激活函数为z，损失函数为L，误差 = L(z(w))，根据链式法则，计算w的梯度，就是 ​δL/δLz * 

#### 反向传播实例

----
举例：

假设我们有一个简单的3层神经网络：
- 输入层：2个神经元 (x₁, x₂)
- 隐藏层：2个神经元 (h₁, h₂)，使用sigmoid激活函数
- 输出层：1个神经元 (o₁)，使用sigmoid激活函数

**网络结构：**
```
输入层 → 隐藏层 → 输出层
```

**前向传播**

设：
- 输入：x = [x₁, x₂] = [0.5, 0.3]
- 真实标签：y = 1
- 学习率：η = 0.5

权重初始化：
```
w₁₁ = 0.1, w₁₂ = 0.2  (x₁ → h₁, h₂)
w₂₁ = 0.3, w₂₂ = 0.4  (x₂ → h₁, h₂)
w₃₁ = 0.5, w₃₂ = 0.6  (h₁, h₂ → o₁)
b₁ = 0.1, b₂ = 0.2    (隐藏层偏置)
b₃ = 0.3              (输出层偏置)
```

**前向传播计算：**
1. 隐藏层输入：
   ```
   net_h₁ = w₁₁×x₁ + w₂₁×x₂ + b₁ = 0.1×0.5 + 0.3×0.3 + 0.1 = 0.24
   net_h₂ = w₁₂×x₁ + w₂₂×x₂ + b₂ = 0.2×0.5 + 0.4×0.3 + 0.2 = 0.42
   ```

2. 隐藏层输出（sigmoid激活）：
   ```
   h₁ = σ(net_h₁) = 1/(1+e^(-0.24)) ≈ 0.56
   h₂ = σ(net_h₂) = 1/(1+e^(-0.42)) ≈ 0.60
   ```

3. 输出层输入：
   ```
   net_o₁ = w₃₁×h₁ + w₃₂×h₂ + b₃ = 0.5×0.56 + 0.6×0.60 + 0.3 = 0.28 + 0.36 + 0.3 = 0.94
   ```

4. 最终输出：
   ```
   o₁ = σ(net_o₁) = 1/(1+e^(-0.94)) ≈ 0.72
   ```

5. 计算损失（均方误差）：
   ```
   L = ½(y - o₁)² = ½(1 - 0.72)² = ½(0.28)² ≈ 0.0392
   ```

---

**反向传播**

1. 计算输出层梯度

**目标：** 计算 ∂L/∂w₃₁, ∂L/∂w₃₂, ∂L/∂b₃

使用链式法则：
```
∂L/∂w₃₁ = ∂L/∂o₁ × ∂o₁/∂net_o₁ × ∂net_o₁/∂w₃₁
```

**逐步计算：**
- ∂L/∂o₁ = -(y - o₁) = -(1 - 0.72) = -0.28
- ∂o₁/∂net_o₁ = o₁(1 - o₁) = 0.72×(1-0.72) ≈ 0.2016 (sigmoid导数)
- ∂net_o₁/∂w₃₁ = h₁ = 0.56


> [!NOTE] 为什么∂L/∂o₁是-(y - o₁)
> 因为损失函数$L=\frac{1}{2}(y-o_1)^2$，根据链式法则，将$t = y-o_1$，$L = \frac{1}{2}t^2$，分别求导，然后相乘，$∂L/∂o₁=t \cdot -1 = -(y-o_1)$
> 
> **∂L/∂o₁的含义**
> ∂L/∂o₁就相当于$y=x_1^2+x_2^2$，然后对$x_1$进行求导，就是∂L是输出值，∂o₁是输入值，∂L/∂o₁就是对$L=\frac{1}{2}(y-o_1)^2$函数求导
> 同样的∂o₁/∂net_o₁就是对激活函数sigmoid求导
> ∂net_o₁/∂w₃₁就是对w₃₁×h₁ + w₃₂×h₂ + b₃进行求导
> 然后通过链式法则相乘得到∂L/∂w₃₁的梯度


**所以：**
```
∂L/∂w₃₁ = (-0.28) × 0.2016 × 0.56 ≈ -0.0316
∂L/∂w₃₂ = (-0.28) × 0.2016 × h₂ = (-0.28)×0.2016×0.60 ≈ -0.0339
∂L/∂b₃ = (-0.28) × 0.2016 × 1 ≈ -0.0564
```

**更新输出层参数：**
```
w₃₁' = w₃₁ - η×∂L/∂w₃₁ = 0.5 - 0.5×(-0.0316) ≈ 0.5158
w₃₂' = w₃₂ - η×∂L/∂w₃₂ = 0.6 - 0.5×(-0.0339) ≈ 0.6170
b₃' = b₃ - η×∂L/∂b₃ = 0.3 - 0.5×(-0.0564) ≈ 0.3282
```


2. 计算隐藏层梯度

**目标：** 计算 ∂L/∂w₁₁, ∂L/∂w₁₂, ∂L/∂w₂₁, ∂L/∂w₂₂, ∂L/∂b₁, ∂L/∂b₂

以 ∂L/∂w₁₁ 为例：
```
∂L/∂w₁₁ = ∂L/∂h₁ × ∂h₁/∂net_h₁ × ∂net_h₁/∂w₁₁
```

**关键点：** ∂L/∂h₁ 需要从输出层反向传播过来：
```
∂L/∂h₁ = ∂L/∂o₁ × ∂o₁/∂net_o₁ × ∂net_o₁/∂h₁
       = (-0.28) × 0.2016 × w₃₁
       ≈ (-0.28)×0.2016×0.5 ≈ -0.0282
```


> [!NOTE] 为什么要计算∂L/∂h₁
> 因为上面输出层是要计算输出层的梯度，所以要到∂L/∂w₃₁，而隐藏层梯度要到∂L/∂w₁₁，而w₁₁与w₃₁无关，有关的是h₁，然后从h₁再到w₁₁



**继续计算：**
- ∂h₁/∂net_h₁ = h₁(1 - h₁) = 0.56×(1-0.56) ≈ 0.2464
- ∂net_h₁/∂w₁₁ = x₁ = 0.5

**所以：**
```
∂L/∂w₁₁ = (-0.0282) × 0.2464 × 0.5 ≈ -0.00347
```

类似地计算其他参数：
```
∂L/∂w₂₁ = ∂L/∂h₁ × ∂h₁/∂net_h₁ × ∂net_h₁/∂w₂₁
        = (-0.0282) × 0.2464 × x₂ = (-0.0282)×0.2464×0.3 ≈ -0.00208

∂L/∂b₁ = ∂L/∂h₁ × ∂h₁/∂net_h₁ × 1 ≈ (-0.0282)×0.2464 ≈ -0.00695
```

对于 h₂ 相关的参数，需要先计算 ∂L/∂h₂：
```
∂L/∂h₂ = ∂L/∂o₁ × ∂o₁/∂net_o₁ × ∂net_o₁/∂h₂
       = (-0.28) × 0.2016 × w₃₂ ≈ (-0.28)×0.2016×0.6 ≈ -0.0339
```

然后：
```
∂L/∂w₁₂ = ∂L/∂h₂ × ∂h₂/∂net_h₂ × ∂net_h₂/∂w₁₂
        = (-0.0339) × [h₂(1-h₂)] × x₁
        = (-0.0339) × [0.60×(1-0.60)] × 0.5
        = (-0.0339) × 0.24 × 0.5 ≈ -0.00407

∂L/∂w₂₂ = ∂L/∂h₂ × ∂h₂/∂net_h₂ × ∂net_h₂/∂w₂₂
        = (-0.0339) × 0.24 × x₂ = (-0.0339)×0.24×0.3 ≈ -0.00244

∂L/∂b₂ = ∂L/∂h₂ × ∂h₂/∂net_h₂ × 1 ≈ (-0.0339)×0.24 ≈ -0.00814
```

**更新隐藏层参数：**
```
w₁₁' = 0.1 - 0.5×(-0.00347) ≈ 0.1017
w₂₁' = 0.3 - 0.5×(-0.00208) ≈ 0.3010
b₁' = 0.1 - 0.5×(-0.00695) ≈ 0.1035

w₁₂' = 0.2 - 0.5×(-0.00407) ≈ 0.2020
w₂₂' = 0.4 - 0.5×(-0.00244) ≈ 0.4012
b₂' = 0.2 - 0.5×(-0.00814) ≈ 0.2041
```

**观察**

1. **链式法则的层级结构**：
   - 输出层梯度直接依赖于预测误差 (y - o₁)
   - 隐藏层梯度依赖于"传播过来的误差" ∂L/∂h

2. **误差信号传播**：
   ```
   输出层误差 → 隐藏层误差 → 输入层权重更新
   ```

3. **计算模式**：
   - 对于权重：`梯度 = 后一层误差信号 × 当前层激活导数 × 前一层输出`
   - 对于偏置：`梯度 = 后一层误差信号 × 当前层激活导数`

> [!NOTE] 关于计算模式
> **权重**：
> 比如计算w1的梯度：∂L/∂w₁₁ = ∂L/∂h₁ × ∂h₁/∂net_h₁ × ∂net_h₁/∂w₁₁
> >- 其中 ∂L/∂h₁是后一层的误差信号，这个意思是后一层对输入的梯度（h₁就是后一层的输入）
> >- ∂h₁/∂net_h₁就是当前激活函数的导数（同时h₁又是这一层的输出）
> >- ∂net_h₁/∂w₁₁=x₁ 就是输入层的输出,这个就是加权求和函数的导数（这个x₁在这是输入层，如果是在神经网络内部，那就是上一层的输出，跟h₁一样，只不过是上一层的）
> 
 > **偏置**
 > 
 
 
 



> [!NOTE] 后一层误差信号
> 还是看∂L/∂w₁₁ = ∂L/∂h₁ × ∂h₁/∂net_h₁ × ∂net_h₁/∂w₁₁，后一层的误差信号是∂L/∂h₁，所以
> 
> 在前向传播



4. **效率**：通过保存前向传播的中间结果（h₁, h₂, o₁等），反向传播可以高效地复用这些值。

这个过程会重复进行，直到网络收敛。每次迭代都会让预测值 o₁ 更接近真实值 y = 1。

#### 关于前向和反向传播

对于任意线性变换 `y = W × x`：

- 前向：`y = W × x`
    
- 反向：`∂L/∂x = Wᵀ × ∂L/∂y`

#### 激活层

```python
# 激活层  
class Relu:  
    def __init__(self):  
        self.mask = None  
  
    def forward(self, x):  
        self.mask = (x <= 0)  
        out = x.copy()  
        out[self.mask] = 0  
        return out  
  
    def backward(self, dout):  
        dout[self.mask] = 0  
        dx = dout  
        return dx  
  
  
class Sigmoid:  
    def __init__(self):  
        self.out = None  
  
    # 前向传播  
    def forward(self, x):  
        out = 1 / (1 + np.exp(-x))  
        self.out = out  
        return out  
  
    # 反向传播  
    def backward(self, dout):  
        dx = dout * (1.0 - self.out) * self.out  
        return dx
```

\frac{1}{t}
\end{aligned}
$$


#### Affine层 (加权求和)

对于$Y = X \cdot W + B$
$$ \begin{aligned} 
\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y} \cdot \frac{\partial Y}{\partial X} = \frac{\partial L}{\partial Y} \cdot W^T \\
\frac{\partial L}{\partial W} = \frac{\partial L}{\partial Y} \cdot \frac{\partial Y}{\partial W} = X^T\cdot\frac{\partial L}{\partial Y}  
\end{aligned} 
$$

class Affine:

        self.b = b  
        self.x = None  
        self.dW = None  
        self.db = None

        out = np.dot(x, self.W) + self.b

    def backward(self, dout):

#### SGD

SGD 的全称是 **随机梯度下降**。
**梯度下降**：就是你用手杖（或凭脚感）感受脚下山坡**最陡峭的下坡方向**，然后向那个方向迈出一步。
**随机**：SGD 不是在整个数据集上计算梯度，而是在**每次参数更新时，只随机选取一个训练样本**来计算梯度。

**更新公式**
$$
\dot W = W - η\frac{\partial L}{\partial W}
$$

**优点**
- 速度快，因为计算量小
- 由于梯度的方向是随机的、嘈杂的，它更容易“跳出”小的坑洼（局部最小值），从而有可能找到更好的（全局）最小值。
- 在线学习：可以随时用新来的数据更新模型，而不需要重新处理整个历史数据。

**缺点**
- 因为是只随机选取一个训练样本，所以会导致梯度方向不是整个最小值方向，会成一个“之”字形下降
- 它会在最小值附近来回跳动，而不是稳稳地停在最优点。


> [!NOTE] 批量随机下降（**BGD**）
> 这意味着算法会遍历**整个训练数据集**，计算所有样本的损失梯度，然后求平均值，最后用这个平均梯度来更新一次模型参数。优点就是方向稳定，朝着目标前进的路径很直接。缺点就是计算缓慢
> 
> **折中方法就是使用小批量梯度方法，现在，在深度学习的文献和框架中，当人们说“SGD”时，通常指的就是这种“小批量梯度下降”**。


**代码实现**
```python
class SGD:  
    def __init__(self, lr=0.01):  
        self.lr = lr  
    def update(self, params, grads):  
        for key in params.keys():  
            params[key] -= self.lr * grads[key]
```

#### Momentum

**Momentum（动量）** 是一个在优化算法，尤其是在梯度下降法中广泛使用的概念，它专门用来解决**普通SGD（随机梯度下降）的缺点**。**Momentum（动量）** 是一种通过**引入“惯性”** 来加速梯度下降并减少优化过程震荡的技术。

**更新公式**
$$
\begin{aligned}
v = αv - η\frac{\partial L}{\partial W} \\
\dot W = W + v 
\end{aligned}
$$
与SGD相似，W表示要更新的权重参数，表示损失函数关于W的梯度，η表示学习率。


> [!NOTE] 如何理解**Momentum**
> 核心就是增加一个动量，动量带有“惯性”，因为动量保存这上一次的梯度，所以不会剧烈震荡，即收敛“之”字形运动，减弱变动程度
> 对于梯度下降的方向，X轴方法，因为保存上一次，而且是同一个方向，所以会有加速
> 对于Y轴方向每次梯度相反，上一次的梯度和这一次相反，会导致这一次的Y轴方法减小，所以会收敛


**优点**
1. **加速收敛**：在相关方向上实现更快的下降。
    
2. **减少震荡**：平滑优化路径，尤其是在损失函数的“峡谷”地形中。
    
3. **帮助逃离局部最优/平坦区**：依靠积累的动量冲过障碍。



**代码实现**

```python
class Momentum:  
    def __init__(self, lr=0.01, momentum=0.9):  
        self.lr = lr  
        self.momentum = momentum  
        self.v = None  
    def update(self, params, grads):  
        if self.v is None:  
            self.v = {}  
            for key, val in params.items():  
                self.v[key] = np.zeros_like(val)  
        for key in params.keys():  
            self.v[key] = self.momentum*self.v[key] - self.lr*grads[key]  
            params[key] += self.v[key]
```

#### AdaGrad

在标准的SGD中，所有参数都使用**同一个全局学习率**。在学习的时候，为了更精细的参数调整，会逐渐减小学习率的值，但是固定的学习率可能不是最优的，所以**AdaGrad（自适应梯度算法）会自动为每个参数调整学习率**

**AdaGrad的核心创新在于：**

- **为每个参数自动计算其专属的学习率**
    
- **不常用的参数** → 获得**更大的更新**
    
- **常用的参数** → 获得**更小的更新**


**更新公式**
$$
\begin{aligned}
h = h + \frac{\partial L}{\partial W} \bigodot \frac{\partial L}{\partial W} \\ \\
W = W - η \frac{1}{\sqrt{h}} \frac{\partial L}{\partial W}
\end{aligned}
$$


> [!NOTE] 为何有效
> h是之前所有梯度的和，h会越来越大，而$\frac{η}{\sqrt{h}}$会越来越小，会导致学习越深入，更新幅度越小

**AdaGrad** 是一种自适应学习率优化算法，它通过：

1. **累积每个参数的历史梯度平方和**
    
2. **用这个累积量来自动调整每个参数的学习率**
    
3. **让不频繁更新的参数获得更大更新，频繁更新的参数获得更小更新**


**优点**
1. **自动适应不同参数**：无需手动为不同特征设置不同学习率
    
2. **适合稀疏数据**：对不频繁出现的特征效果特别好
    
3. **减少超参数调优**：学习率自动衰减，无需设计复杂的学习率调度器


**缺点**
1. **学习率单调递减至0**：
    
    - 由于 `G_t` 只增不减，学习率 `α/√G_t` 会持续下降
        
    - 在训练后期，学习率变得极小，几乎停止更新
        
    - 可能**无法收敛到最优解**
        
2. **需要设置合适的初始学习率**：
    
    - 如果初始 `α` 设置不当，可能一开始学习就太慢

**代码实现**

```python
class AdaGrad:  
    def __init__(self, lr=0.01):  
        self.lr = lr  
        self.h = None  
    def update(self, params, grads):  
        if self.h is None:  
           self.h = {}  
           for key, val in params.items():  
               self.h[key] = np.zeros_like(val)  
        for key in params.keys():  
            self.h[key] += grads[key] * grads[key]  
            # 1e-7 防止除以零  
            params[key] -= self.lr * grads[key] / (np.sqrt(self.h[key]) + 1e-7)
```


#### RMSProp

**AdaGrad的缺点**：学习率**单调递减至0**，因为梯度平方和只增不减，会导致训练后期几乎停止更新

而**RMSProp**会让历史数据的影响逐渐减弱，而不是永久记录，这样学习率不会一致下降，

可以把RMSProp理解为 **"带衰减的AdaGrad"**：

- **AdaGrad**：记住**所有历史梯度**，越记越多
    
- **RMSProp**：只关注**最近一段时间的梯度**，旧的梯度逐渐被遗忘


**更新公式**
$$
\begin{aligned}
h = ρ * h + (1-ρ) * \frac{\partial L}{\partial W} \bigodot \frac{\partial L}{\partial W} \\ \\
W = W - η \frac{1}{\sqrt{h}} \frac{\partial L}{\partial W}
\end{aligned}
$$



> [!NOTE] 为何有效？
> 在刚开始的时候，梯度很大，得到的h很大，学习率变小，后期梯度变小，h开始**衰减**（因为旧的大的梯度被遗忘），最终会稳定在一个合理的水平，学习率不再无限下降


**参数设置**

- **ρ（衰减率）**：通常设为0.9、0.99、0.999
    
    - 值越大，历史信息记得越久
        
    - 值越小，对当前梯度变化越敏感
        
- **α（学习率）**：由于自适应机制，通常可以设得比SGD大一些
    
- **ε**：很小的数（如1e-8），防止除以零

**RMSProp + Momentum = Adam**

- **从Momentum借鉴**：使用**梯度的一阶矩（均值）** 来保持"惯性"，加速收敛并减少震荡

### 权重的初始值

#### 权重值的设置

**不能设置全部为0或为同一个值**，因为如果同一层的所有神经元初始权重相同，那么在反向传播时，它们会计算出完全相同的梯度，并进行完全相同的更新。这意味着这些神经元将永远保持一致，整个层的行为就像单个神经元一样，严重破坏了网络的学习能力。


**随机初始化**
从一个标准高斯分布（均值0，标准差1）中随机采样，然后乘以一个很小的数（如0.01），**缺点：** 就是对于深层网络，这个“很小的数”是随意选择的，可能效果很差，导致梯度消失

```python
# Python 示例
import numpy as np

W = np.random.randn(fan_in, fan_out) * 0.01 # 从高斯分布采样，并缩小100倍
```


> [!NOTE] 为什么要乘以一个很小的数
> 
> **1.防止输入信号在经过激活函数（如tanh, sigmoid）时过大，导致饱和（梯度接近0）**
> 比如sigmoid函数，它的导数$f'(x) = f(x)(1-f(x))$，当数据过大，f(x)就越接近于1，那么1-f(x)就越接近于0，f'(x)就越小，同样很小的值也不行，乘一个很小的值，就正好落在梯度最大范围，因为sigmoid函数梯度最大范围在0附近
> 
> **2. 保持信号稳定，防止梯度爆炸**
> 如果神经网络有多层神经，每一层的权重都大于1，那么在前向传播的时候，就会导致数据会非常大，会导致溢出，同样反向传播也是如此，也会导致梯度变大，然后每一层的梯度相乘，导致**梯度爆炸**，梯度爆炸会导致模型参数更新步长过大，导致模型无法收敛，在最优点附近来回震荡
>

**现代标准化初始化方法**

**a)、Xavier/Glorot 初始化**
这种方法适用于 **Tanh** 和 **Sigmoid** 等饱和型激活函数。初始化时，应使每一层输出的**方差**尽可能等于其输入的方差。从而确保信号在深层网络中传播时会被过度放大或缩小。

> [!NOTE] 饱和性激活函数

**b)、He/Kaiming 初始化**
这种方法专为 **ReLU** 及其变体（如Leaky ReLU）设计。因为ReLU会将负数置零，其输出的方差与输入不同。根据ReLU的特性，调整方差的计算。

> [!NOTE] 如何理解方差
> **方差**是统计学和概率论中一个核心的概念，用于衡量一组数据或随机变量的**离散程度**或**波动大小**。它描述了数据点与其平均值之间的平均平方距离。
> $$ \begin{align}
> 平均值：μ = \frac{1}{n}\sum_n^{i=1}{x_i} \\
> 总方差：μ = \frac{1}{n}\sum_n^{i=1}{(x_i-μ)^2} \\
> 样本方差：μ = \frac{1}{n}\sum_n^{i=1}{(x_i-\overline{x})^2}
> \end{align}
> $$
> 
> **比如**
> - 班级A的平均分 = (70+72+75+78+80)/5 = **75分**
>- 班级B的平均分 = (50+60+75+90+100)/5 = **75分**
>
>两个班的平均分都是75分！如果只看平均值，你会认为两个班的成绩水平是一样的。但是班级A的成绩都集中在70-80分之间，比较稳定。班级B的成绩从50分到100分，分布非常广，波动巨大。
>
>**标准差**
>对方差开平方根得到标准差
>
>**方差对权重的意义**
>方差小代表波动小，方差越小代表越聚集
>方差大代表波动大，方差大代表越分散
>所以方差既不能太大也不能太小，太大会主导整个模型，导致其他特征被忽略。同时，过大的输入值会使后续神经元迅速进入饱和区（如Sigmoid函数的两端），导致梯度接近于零，从而出现**梯度消失**问题。太小（全为0或者接近0）表示这个特征不提供任何信息，模型无法从中学习。其权重梯度也会很小，导致学习停滞。**所以方差要≈1**
>
>**为什么方差要≈1？**
>方差 ≫ 1时，经过多层连乘，激活值会变得极大，导致梯度爆炸
>方差 ≪ 1时，信号会迅速衰减，梯度趋近于零
>Var(y) = n × Var(W) × Var(x)
>Var(W)：权重的方差
>Var(X)：输入的方差
>n：表示输入的维度
>
>**输出的方差与输入值有关，那么为什么我们不考虑输入值的方差，而只关注权重的方差？**
>在讨论权重初始化时，我们通常**隐含地假设输入数据已经被标准化**，对于输入数据我们通过标准化使Var(X)≈1，对于前一层输出，通过BatchNorm等技术，使Var(X)≈1

**sigmoid**

```python
import numpy as np  
import matplotlib.pyplot as plt  
  
def sigmoid(x):  
    return 1 / (1 + np.exp(-x))  
  
x = np.random.randn(1000, 100) # 1000个数据  
node_num = 100        # 各隐藏层的节点（神经元）数  
hidden_layer_size = 5 # 隐藏层有5层  
activations = {}      # 激活值的结果保存在这里  
for i in range(hidden_layer_size):  
    if i != 0:  
        x = activations[i-1]  
    w = np.random.randn(node_num, node_num) * 1  
    z = np.dot(x, w)  
    a = sigmoid(z)   # sigmoid函数  
    activations[i] = a  
  
# 绘制直方图  
for i, a in activations.items():  
    plt.subplot(1, len(activations), i + 1)  
    plt.title(str(i + 1) + "-layer")  
    plt.hist(a.flatten(), 30, range=(0, 1))  
plt.show()
```

**ReLU**

Xavier初始值是以激活函数是线性函数为前提而推导出来的。因为sigmoid函数和tanh函数左右对称，且中央附近可以视作线性函数，所以适合使用Xavier初始值。但当激活函数使用ReLU时，一般推荐使用ReLU专用的初始值，也就是Kaiming He等人推荐的初始值，也称为“He初始值”。 当前一层的节点数为n时，He初始值使用标准差为 $\sqrt{2/n}$的高斯分布。当Xavier初始值是$\sqrt{1/n}$时，（直观上）可以解释为，因为ReLU的负值区域的值为0，为了使它更有广度，所以需要2倍的系数。

```python
import numpy as np  
import matplotlib.pyplot as plt  
import math  
  
def sigmoid(x):  
    return 1 / (1 + np.exp(-x))  
  
def relu(x):  
    return np.maximum(0, x)  
  
def tanh_math(x):  
    """使用math模块实现tanh函数"""  
    return np.tanh(x)  
  
x = np.random.randn(1000, 100) # 1000个数据  
node_num = 100        # 各隐藏层的节点（神经元）数  
hidden_layer_size = 5 # 隐藏层有5层  
activations = {}      # 激活值的结果保存在这里  
for i in range(hidden_layer_size):  
    if i != 0:  
        x = activations[i-1]  
    # w = np.random.randn(node_num, node_num) * 1  
    # w = np.random.randn(node_num, node_num) * 0.01    # w = np.random.randn(node_num, node_num) / np.sqrt(node_num)    w = np.random.randn(node_num, node_num) / np.sqrt(2 / node_num)  
    z = np.dot(x, w)  
    # a = sigmoid(z)   # sigmoid函数  
    # a = tanh_math(z)  # sigmoid函数  
    a = relu(z)       # relu函数  
    activations[i] = a  
  
# 绘制直方图  
for i, a in activations.items():  
    plt.subplot(1, len(activations), i + 1)  
    plt.title(str(i + 1) + "-layer")  
    plt.hist(a.flatten(), 30, range=(-1, 1))  
plt.show()
```
